## Madoku Craft: HUD

Madoku Craft: HUD overhauls Minecraft's HUD system.
It compacts the UI and adds additional HUDs to display more information.
You can enable and disable which UIs are displayed in the CONFIG file.

## Dependencies

This MOD requires Fabric API and Madoku Craft API in order to function properly.
This MOD uses Madoku Craft API's JSON, TICK, and Debug systems.

## Implementation

This MOD adds a HUD on the top left of the screen.
It displays the in-game day, and time.
It also shows the current biome the player is in.
The existing HUDs were compacted to display the values instead of just icons.
